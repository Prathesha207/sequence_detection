# SOP sequence monitor — training + inference

This folder holds the desktop app's **Train model** and **Run inference**, as plain scripts without the window.
It is the same engine code `app.py` runs today (25 Nov), including:
- online confirmation;
- the step lifecycle (taken / put back / let go, DINOv2 check, early order warnings);
- completion landmarks with self-correcting step timing;
- 30 fps everywhere.

```
sequence_training_inference/
├── training/
│   ├── train_sequence.py    SOP + good video + detector -> a trained sequence model (the app's 7 training stages)
│   ├── sop_engine.py        the whole training engine in ONE file (generated by tools/, do not edit)
│   └── config.json          fps (30 = every frame) and the step model (TCN / LSTR)
├── inference/
│   ├── infer.py             the whole inference in ONE file (= inference_code_only/infer.py), class SOPMonitor = API
│   └── example_integration.py
├── train.py                 APPLICATION training entry: --input --output_dir --data_path --weights -> model package
├── infer.py                 APPLICATION inference entry: --model_dir <package> --input <video> -> result.json
├── sequence_registry.py     build_train_args / build_infer_args / SEQUENCE_MODEL: the command lines for an app
├── models.json              detector registry (paths relative to this folder)  ─┐
├── weights/                 detectors/*.pt, hand_landmarker.task, DINOv2        ├ shared: training writes trained/,
├── trained/                 the trained sequence models + active_model.txt     ─┘ inference reads it
└── tools/build_training_engine.py   rebuilds training/sop_engine.py from the app's sopmon/
```

Use the same Python as the app (`C:\Users\sonar\Desktop\apple-anoloading\Inference\Scripts\python.exe`).
In PowerShell, put `&` before a command held in a variable: `& $py ...`.

## 0. Use from an application: `train.py` → model package → `infer.py`

Two entry points sit at the top of this folder. The application passes only what it owns: the paths, the
input video, the trained detector and the SOP. The model's own settings stay in `training/config.json`.

```powershell
& $py train.py --input good.mp4 --output_dir <results_path> --data_path <job dir> `
    --weights <detector best.pt> [--prompt "1. ... 2. ..."]
& $py infer.py --model_dir <results_path> --input test.mp4 [--output_dir <dir>] [--no_preview]
```

- **Where the SOP comes from:** `--prompt` or `--prompt_file`. Without either, `train.py` reads `sop_prompt.txt`,
  `sop.txt`, `prompt.txt` or `job.json {"prompt"}` from `--data_path`.
- **The training output is a self-contained model package:**
  - `models.json`;
  - `weights/detectors/*.pt`, the detector it was trained with;
  - `weights/dinov2_vits14.safetensors` and `weights/hand_landmarker.task`, the shared models;
  - `trained/<name>/` and `trained/active_model.txt`;
  - `sop_prompt.txt`;
  - `result.json`.

  `infer.py --model_dir` runs exactly that package, so inference always uses the model and detector that were
  trained together.
- **Exit codes:**
  - `train.py`: 0 = trained, 2 = training failed (`result.json` has `error`), 1 = unexpected error.
  - `infer.py`: 0 = every input NORMAL, 3 = an ANOMALY or UNCERTAIN, 2 = a bad package or input.
    `<output_dir>/result.json` holds the verdict, steps and times for each input.
- **`--video_to_frames` / `--stream_mode`** are accepted but not needed: the video is read directly at 30 fps,
  with no frame folder.
- **From Python:** `import infer; mon = infer.load_monitor(model_dir)`, then `mon.start()`,
  `mon.process_frame(frame, t)` and `mon.stop()`.
- **Command lines for an app:** `sequence_registry.py` has `build_train_args(job)`, `build_infer_args(job)`,
  `train_command(job)`, `infer_command(job)` and the `SEQUENCE_MODEL` entry (scripts, outputs, exit codes). It
  has no outside imports.

## 1. Train

```powershell
$py = "C:\Users\sonar\Desktop\apple-anoloading\Inference\Scripts\python.exe"
cd C:\Users\sonar\Desktop\OpenVocab_SOP_Monitor\sequence_training_inference\training

& $py train_sequence.py --video "C:\path\good.mp4" --detector "assembling_box_model (detect)" `
    --prompt "Packing a Lenovo box 1. Open the box. 2. Put the mouse into the open box. 3. Put the instruction card into the open box. 4. Put the pen marker into the open box. 5. Close the box."
```

**Options:**
- `--prompt-file sop.txt`: read the SOP from a file instead of `--prompt`.
- `--detector NAME`: the detector to use (repeatable). The default is every detector enabled in `models.json`.
- `--kind LSTR`: use the LSTR step model instead of the TCN.
- `--fps 30`: the training frame rate. The default comes from `config.json`; 30 uses every frame.
- `--name my_model`: the model name. The default is `<video>_<date>_<time>`.

**The SOP must be numbered** (`1. ... 2. ...`), and every step must name one of the detector's classes. If a
step's words differ from the class name, write the class in brackets: `5. Close the box (close_box)`. No VLM is
used.

**The good video** must show the SOP done correctly: every step, in order.

**The result** is saved in `trained/<name>/` and becomes the **active** model, so inference uses it next. The log
ends with the self-check (NORMAL = it recognises its own good video).

**A new detector:** put its `.pt` in `weights/detectors/` and add an entry to `models.json`. Copy an existing
entry and change `name`, `path` and `classes`.

## 2. Inference

```powershell
cd C:\Users\sonar\Desktop\OpenVocab_SOP_Monitor\sequence_training_inference\inference
& $py infer.py --list                                  # the trained models (* = active)
& $py infer.py --video "C:\path\test.mp4"              # the active model
& $py infer.py --model <name> --video a.mp4 b.mp4 --save_video
& $py infer.py --video 0                               # camera 0 (Q ends the session)
```

The options and the `SOPMonitor` API are the same as in `inference_code_only` (see its README):
- `--no_preview`, `--real_time`, `--print_frames`, `--no_excel`;
- `--fps 0` runs at the model's trained rate instead of 30 fps.

Results go to `outputs/<date>/<video>/<time>_infer/`.

## Keeping it up to date with the app

The engine in both files is a copy of the app's `sopmon/` as of 25 Nov. After engine changes in the app, run:
```powershell
cd C:\Users\sonar\Desktop\OpenVocab_SOP_Monitor
& $py inference_code_only\tools\sync_engine.py                                  # inference_code_only\infer.py
Copy-Item inference_code_only\infer.py sequence_training_inference\inference\infer.py
& $py sequence_training_inference\tools\build_training_engine.py                # training\sop_engine.py
```
